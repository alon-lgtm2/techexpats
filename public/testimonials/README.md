# Testimonial profile photos

Drop each reviewer's profile photo here. The filename must match exactly what is set
in `src/data/testimonials.ts` (the `avatar:` field), or the card falls back to the
person's initials automatically (no broken image).

Square images work best (they are cropped to a circle). 200x200px or larger is plenty.
Use `.jpg`; if you have a `.png`/`.webp`, either rename it to `.jpg` or update the
`avatar:` path in the data file.
