# Article hero photos

Drop an article's hero image here. The filename must match the `image:` path set in that
article (frontmatter), e.g. `image: "/insights/my-new-article.jpg"` -> save the file as
`my-new-article.jpg` in this folder.

- Landscape / 16:9 looks best (it renders as the article hero and as the card thumbnail).
- Use `.jpg` (or update the `image:` path to match your file's extension).
- If the file is missing, the article simply shows no hero image (nothing breaks).
